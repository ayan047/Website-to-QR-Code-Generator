# 📱 QR Code Generator Using Python

✨ **Generate QR codes for any website URL in just a few clicks!**

## 🎯 Project Overview

This project is a simple and user-friendly **QR Code Generator** built with Python. It allows users to instantly convert website URLs into QR codes through an intuitive graphical user interface (GUI).

Users simply need to copy a website URL, paste it into the input field, and generate their QR code. They can also save the generated QR code as a **PNG image** for future use, sharing, or printing. 🌐📷

## ✨ Key Features

- 🌐 **URL to QR Code:** Convert website links into scannable QR codes.
- 🖥️ **Interactive GUI:** Generate QR codes without using command-line instructions.
- ⚡ **Quick Generation:** Create QR codes with just a few clicks.
- 💾 **Save as PNG:** Export generated QR codes as PNG image files.
- 📱 **Easy to Scan:** Create QR codes that can be scanned using compatible smartphones and QR code readers.
- 🎨 **Simple & User-Friendly:** Enjoy a clean and straightforward user experience.

## 🛠️ Technologies Used

- 🐍 **Python** — Core programming language.
- 🔳 **qrcode Module** — For generating QR codes from website URLs.
- 🖼️ **Pillow (PIL)** — For creating, processing, and displaying QR code images.
- 🪟 **Tkinter** — For developing the graphical user interface.

## 👨‍💻 Project Responsibilities

- 🔳 Implemented QR code generation for website URLs.
- 🖥️ Designed a user-friendly GUI for smooth interaction.
- 🌐 Enabled users to enter website URLs with ease.
- 💾 Implemented functionality to save QR codes as PNG images.
- ✅ Focused on generating clean, functional, and scannable QR codes.

## 🎯 Project Objective

The primary objective of this project is to make QR code generation **simple, fast, and accessible to everyone** through a desktop application that requires no advanced technical knowledge.
